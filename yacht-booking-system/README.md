# Yacht Booking System images

Original images used by MagePeople Yacht Booking System and the bundled Yachtiva theme.

- `demo/`: the original five-photo galleries for each of the six demo yachts.
- `admin/guide/`: full-resolution admin help screenshots.
- `admin/yachtiva-demo.png`: the demo website preview.
- `theme/screenshot.png`: the Yachtiva theme screenshot.
- `map/leaflet/`: original Leaflet map controls and marker images.

Every image is copied byte for byte from the existing products. No resizing, recompression or quality reduction has been applied. `manifest.json` records SHA-256 checksums, byte counts and dimensions. The Free and Pro demo importers share the same original yacht photographs.

Client installers download the demo photos only during demo import and retain them in the WordPress Media Library. The admin help and theme preview can load these originals directly. Imports use an immutable repository revision and verify the downloaded file checksum.

Existing image licensing and credits apply; see the accompanying theme asset credits and Leaflet license.
